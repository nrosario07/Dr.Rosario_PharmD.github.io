# Texas CPA authority and notification — v0.9.0

Reviewed October 14, 2026. The core distinction is implementation/modification under protocol versus dangerous-drug prescription signing in specified settings. A pharmacist’s degree, CPA and state scope do not establish payer recognition, independent medical diagnosis or NP/PA status.

| Authority | Scope / requirements | Who submits or acts | Status / source |
|---|---|---|---|
| OC §157.101(b), (b-1)(1) | Qualified/trained delegated pharmacist; physician diagnosis, initial assessment and drug order precede implementation/modification; protocol retained ≥7 years after expiration | Physician delegates, pharmacist maintains protocol; this branch alone does not trigger signing notification | Current statute; [Chapter 157](https://statutes.capitol.texas.gov/Docs/OC/htm/OC.157.htm) |
| OC §157.101(b-1)(2) | Dangerous-drug signing in FQHC/hospital/hospital clinic/academic institution with authorizing bylaws/medical-staff policy; physician prerequisites; both professionals’ prescription identifiers; protocol copy to TSBP | Signing pharmacist follows the separate notification branch | Current statute, not general independent prescribing |
| 22 TAC §295.13(c)(3), LIC-1209 | Notify before signing; attach written protocol initially; changed protocol within 10 days; form requests new application with essential-element changes | Signing pharmacist submits form and protocol to TSBP, not every nonsigning DTM pharmacist | [TSBP rules](https://www.pharmacy.texas.gov/files_pdf/tsbp%20rules_master%20file.pdf); [current form](https://www.pharmacy.texas.gov/files_pdf/LIC-1209.pdf) |
| 22 TAC §295.13(b), (d)–(f) | Written decision/communication criteria, training/annual six-hour drug-therapy CE, supervision, physician relationship, reporting and records | Pharmacist and delegating physician; annual protocol review | Current Board compilation |
| OC §554.057, §554.005 | TSBP rulemaking/DTM enabling provisions; §554.057 implements §157.101(b-1) | Boards adopt rules; not a separate payer license | [Chapter 554](https://statutes.capitol.texas.gov/Docs/OC/htm/OC.554.htm) |
| TMB Chapter 169, Subchapter D, §169.20 | Current delegation rule location; old slide §193.15 is historical after reorganization | Delegating physician’s medical-board duties remain | [TMB current rules and official reorganization matrix](https://www.tmb.texas.gov/laws-rules/occupations-code-board-rules) |
| SB1056 / HB2425, 2019 | Amendments reflected in §157.101; historical effective date September 1, 2019 | Use current codified text rather than proposed bill analysis | [SB1056 enrolled analysis](https://capitol.texas.gov/tlodocs/86R/analysis/pdf/SB01056F.pdf) |
| Insurance Code §1451.128 / HB1757 | Insured’s pharmacist selection for covered, in-scope policy services; no guaranteed code/rate | Applicable insurer/product contract review, separate from CPA | [Chapter 1451](https://statutes.capitol.texas.gov/Docs/IN/htm/IN.1451.htm) |
| OC Chapter 562 | Biological-product substitution duties are separate from delegation; FDA listing alone does not establish state-law compliance | Dispensing pharmacist reviews substitution, communication and labeling requirements | [Chapter 562](https://statutes.capitol.texas.gov/Docs/OC/htm/OC.562.htm) |

The current LIC-1209 form says to allow 15 business days for processing. Statute/rule wording is copy/notification, so this release does not recast all CPAs as applications for Board approval. Confirm submission processing and institutional signing authorization with TSBP before use. Submitted form information is public; the site does not submit forms or retain credentialing documents. Seven-year post-expiration protocol retention is not interchangeable with other records’ retention periods.
