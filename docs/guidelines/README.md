# ClinicalRx Guideline Repository

## Coverage target
Broad coverage across major medical specialties.

## Required metadata
Title; issuing organization; specialty/topic tags; publication and revision dates; first-detected date; version; official source/document URLs; prior version; concise change summary; retrieval timestamp; last successful check; validation state; discovery method.

## Update workflow
1. Check official publisher feed/API/index on schedule.
2. Identify new or changed records.
3. Retrieve official metadata/document.
4. Compare version/date and archive prior metadata.
5. Mark `REVIEW_REQUIRED` if change is not machine-verifiable or clinically material.
6. Publish verified metadata and add it to the rolling six-month banner.
7. Keep older records searchable.

## Initial publisher discovery backlog
ADA; ACC; AHA; ACCP; ASHP; IDSA; ATS; GOLD; GINA; KDIGO; ACOG; AAP; ASH; HIVMA; USPSTF; CDC; FDA; CMS; VA/DoD; AAFP; ACP; AACE; Endocrine Society; AGA; ACG; AASLD; NCCN subject to access/licensing restrictions; and additional specialty organizations after review.

This is a discovery backlog, not a claim that every publisher exposes a free public API. Prefer official RSS/Atom/API feeds. Use page monitoring only when terms permit. Do not scrape login-gated or paywalled content.
